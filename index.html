💡 操作方法:
・クリック → 始点
・再クリック → 終点（フレーム確定）
・描画中は長さ＋角度を表示
・Shift → X/Y/Z軸に固定
・コネクタをクリック → 選択/変更
・Ctrl+D → 選択フレームを複製
・[P] → パネル/扉（対角2点で描画）
・キャップ/フット/キャスターは
　コネクタ欄の「端部パーツ」から選択
・既存の端点に近づくと自動スナップ
・縦フレームは作業平面を
　「正面XY」か「側面YZ」に切替
・Esc → 描画キャンセル
・右ドラッグ → 視点回転
・中ドラッグ / Shift+右 → パン
・ホイール → ズーム
